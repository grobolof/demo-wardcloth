## Как открыть

**Сайт** — витрина магазина. Локально он открывается по адресу из `HTTP_SERVER` в `public/config.php` (в этом проекте — `http://mr-robot.docker.local`), порт **80**.

Имя **`mr-robot.docker.local`** нужно прописать в `/etc/hosts`:

```text
127.0.0.1 mr-robot.docker.local
```

**Админка** — товары, заказы и настройки. Адрес: `http://mr-robot.docker.local/admin/`.

Логин и пароль берутся из `.env`: в примере это `admin` и `password`.

Почта покупателя на локальном стенде никуда не уходит: почтовый сервер не настроен.

## Витрина

### Шапка и подвал

| Элемент | Что произойдёт |
| --- | --- |
| Логотип | Открывает главную. |
| **Каталог** | Раскрывает сетку категорий. Повторное нажатие её закрывает. |
| **Найти** | По мере ввода показывает до пяти подсказок: товар или категорию. Enter открывает страницу поиска. |
| **Войти** | Открывает окно входа. После входа на этом месте **Кабинет** с пунктами **Личный кабинет**, **Заказы**, **Выйти**. |
| **Избранное** | Открывает список избранного. Без входа сначала просит войти. |
| **Корзина** | Открывает `/cart`. Красный кружок показывает число товаров, когда корзина не пустая. |
| Телефон | Набор номера `88001005588`. |
| Ссылки подвала | Ведут в категории, «О магазине», контакты и информационные страницы. |
| **@grobolof** и **исходным кодом** | Открывают профиль и репозиторий проекта в новой вкладке. |

### Главная

| Что нажали | Что произойдёт |
| --- | --- |
| Слайд или **Подробнее** | Открывает категорию этого слайда. |
| Стрелка или точка баннера | Переключает слайд, адрес страницы не меняется. |
| Плитка раздела | Открывает категорию. |
| Название бренда | Открывает товары этого производителя. |
| Карточка товара | Открывает карточку. **В корзину** кладёт товар, не уходя со страницы. Сердце добавляет в избранное. |

### Каталог и карточка товара

В категории сверху кнопки брендов. Активная ведёт на ту же категорию без фильтра, остальные — на товары выбранного бренда.

| Что сделали | Что произойдёт |
| --- | --- |
| Выбрали сортировку или **Показать** | Список перезагружается с новым порядком или числом товаров на странице. По умолчанию на странице 10 товаров. |
| Нажали номер страницы | Открывается эта страница списка. Текущий номер красный, соседние — тёмные. Стрелка справа ведёт на следующую, слева — на предыдущую. |
| Нажали **В корзину** на карточке в списке | Товар попадает в корзину, счётчик в шапке увеличивается. |
| Нажали сердце | Товар добавляется в избранное или убирается, если уже был там. |
| Открыли карточку | Слева фото, по центру название и характеристики, справа цена и **В корзину**. |
| Нажали миниатюру | Большое фото меняется на выбранное. |
| Нажали большое фото | Открывается увеличенное изображение. |
| Товара нет в наличии | Вместо «Есть в наличии» написано «Нет в наличии». В корзину такой товар не кладётся: в настройках магазина покупка при нулевом остатке выключена. |

### Поиск

Пока в поле пусто, подсказок нет. После ввода появляются товары и категории, у которых название подходит к строке. Щелчок по подсказке открывает её сразу. Enter или кнопка лупы открывает `/search` со списком.

Пустой результат показывает текст, что ничего не найдено.

### Корзина и заказ

| Что сделали | Что произойдёт |
| --- | --- |
| Изменили количество | Сумма строки и итог пересчитываются. Меньше 1 поставить нельзя. |
| Удалили товар | Строка исчезает. Если товаров не осталось, корзина пустая. |
| **Скачать файлом** | Браузер сохраняет состав корзины файлом. |
| **Распечатать** | Открывается печать текущей корзины. |
| **Оформить заказ** | Открывается `/checkout`. Пустая корзина сюда не пускает и возвращает в `/cart`. |
| Не заполнили имя, телефон или почту | Под полем появляется ошибка, заказ не создаётся. |
| Не поставили обе галочки | Кнопка **Оформить заказ** неактивна. |
| Поставили галочки и нажали **Оформить заказ** | Создаётся заказ с самовывозом по адресу магазина и оплатой наличными при получении. Доставка бесплатная. |

Гость может оформить заказ без регистрации. Вошедший покупатель видит свои имя, почту и телефон уже заполненными.

### Личный кабинет

| Элемент | Что произойдёт |
| --- | --- |
| Блок с именем | Открывает правку личных данных. **Сменить пароль** ведёт на ту же страницу к полю пароля. |
| **Избранное** | Список сохранённых товаров. |
| **Заказы** | Список заказов. У заказа есть **Повторить заказ** и, пока его можно отменить, **Отменить заказ**. |
| **Выйти** | Завершает сессию и возвращает кнопку **Войти**. |
| **Зарегистрироваться** в окне входа | Открывает `/register`. |
| **Забыли пароль?** | Открывает форму восстановления. Письмо на локальном стенде не отправляется: почта не настроена. |

## Запуск

Нужны Docker и файл `.env` в корне репозитория. Его собирают из `.env.example`.

В `/etc/hosts` добавляют строку `127.0.0.1 mr-robot.docker.local`, затем:

```bash
make up
```

`make up` поднимает контейнер приложения и MariaDB. При первом запуске база заполняется из `docker/mariadb/db.sql`. Повторный запуск этот файл не перечитывает: данные уже лежат в томе Docker.

| Сервис | Зачем | Порт на компьютере |
| --- | --- | --- |
| **application** | OpenCart 4.1 на PHP 8.5. Корень репозитория смонтирован в контейнер. | **80** |
| **database** | MariaDB 11.8. В ней каталог, заказы и настройки. | **3306** |

Остановить контейнеры: `make stop`.  
`make down` удаляет контейнеры и том базы. Следующий `make up` снова загрузит `docker/mariadb/db.sql`.

Код витрины лежит в `public/catalog`: экраны — в `view/template`, оформление — в `view/stylesheet/mrrobot.css`, поведение шапки и корзины — в `view/javascript/mrrobot.js`. Админка — в `public/admin`. Общие классы OpenCart — в `public/system`.

### Переменные `.env`

| Переменная | Зачем |
| --- | --- |
| **`APP_HOST`** | Имя сайта, в этом проекте `mr-robot.docker.local`. Тот же хост записан в `public/config.php` и `public/admin/config.php`. |
| **`APP_PATH`** | Куда внутри контейнера смонтирован репозиторий. |
| **`DB_CONNECTION`** | Драйвер. Для этого проекта — `mariadb`. |
| **`DB_HOST`** | Имя сервиса базы в Docker, `database`. |
| **`DB_PORT`** | Порт MariaDB, `3306`. |
| **`DB_DATABASE`** | Имя базы, в примере `opencart`. |
| **`DB_USERNAME`**, **`DB_PASSWORD`** | Логин и пароль базы. |
| **`OC_DB_PREFIX`** | Префикс таблиц. Если не задан, используется `oc_`. |
| **`OC_ADMIN_USER`**, **`OC_ADMIN_PASSWORD`**, **`OC_ADMIN_EMAIL`** | Учётная запись администратора для первой установки. Уже созданная база их не перезаписывает. |
| **`OC_CRON_ENABLED`** | **`1`** — `php cron.php` запускается раз в минуту. **`0`** — не запускается. |

Пароли из `.env` в инструкцию сверх примера не копируйте: боевые значения хранятся только на сервере.

## Частые вопросы

**Где поменять телефон, адрес или название магазина?**  
В админке: **Система → Настройки**, вкладка магазина. Телефон в шапке берётся из этой настройки.

**Где поменять цену или остаток?**  
**Каталог → Товары**. После сохранения обновите витрину.

**Почему кнопка «Оформить заказ» серая?**  
Не отмечены согласие на обработку персональных данных и согласие с офертой. Оба флажка включают кнопку.

**Почему товар не кладётся в корзину?**  
Остаток нулевой, а покупка без остатка в настройках выключена. На карточке при этом написано «Нет в наличии».

**Куда делось избранное?**  
Список открывается после входа, адрес `/wishlist`. Сердце на карточке запоминает товар для текущего покупателя.

**Почему на категории одна красная страница, а не текст «Показано с…»?**  
Под списком стоят номера страниц. Если товаров меньше, чем выбрано в **Показать**, виден только номер **1**.

**Почему письмо о заказе или пароле не приходит?**  
В локальном `.env` почтовый сервер не задан. Заказ при этом в админке создаётся.

**Почему сайт открывается со старым именем `wardclotch.docker.local`?**  
Актуальный адрес — `http://mr-robot.docker.local`. Его нужно добавить в `/etc/hosts` и открывать им. Старое имя в конфигах больше не используется.

**Нужно ли пересобирать стили после правки `mrrobot.css`?**  
Нет. Файл подключается как есть. Если браузер держит старую копию, обновите страницу.
